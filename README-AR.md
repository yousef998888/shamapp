# 🛍️ شام - سوق إلكتروني

منصة سوق إلكتروني متكاملة مع دعم للغة العربية والإنجليزية، مبنية باستخدام React Native و Supabase.

## 🚀 المميزات

- **واجهة متعددة اللغات**: دعم كامل للعربية والإنجليزية
- **نظام مصادقة متقدم**: تسجيل دخول وخروج آمن
- **إدارة المنتجات**: إضافة وتعديل المنتجات مع الصور
- **نظام البحث الذكي**: بحث متقدم مع دعم الذكاء الاصطناعي
- **إدارة الطلبات**: تتبع الطلبات من البداية للنهاية
- **نظام التقييمات**: تقييم البائعين والمشترين
- **إدارة الموقع**: نظام شامل لإدارة المدن ونقاط الاستلام

## 🛠️ التقنيات المستخدمة

### Frontend
- **React Native** - تطبيق الهاتف المحمول
- **Expo** - منصة التطوير
- **TypeScript** - لغة البرمجة
- **React Navigation** - التنقل بين الشاشات

### Backend
- **Supabase** - قاعدة البيانات والخدمات الخلفية
- **PostgreSQL** - قاعدة البيانات الرئيسية
- **Row Level Security (RLS)** - أمان البيانات
- **Supabase Auth** - نظام المصادقة

### AI & Search
- **OpenAI API** - معالجة النصوص والبحث الذكي
- **Vector Embeddings** - البحث الدلالي
- **Typesense** - محرك البحث المتقدم

## 📋 المتطلبات

- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn
- Expo CLI
- Supabase CLI
- حساب OpenAI (للميزات الذكية)

## 🔧 التثبيت والإعداد

### 1. **استنساخ المشروع**

```bash
git clone <repository-url>
cd sham-marketplace
```

### 2. **تثبيت التبعيات**

```bash
# تثبيت تبعيات المشروع الرئيسي
npm install

# تثبيت تبعيات التطبيق
cd sham-app
npm install

# تثبيت تبعيات الخادم
cd ../server
npm install

# تثبيت تبعيات قاعدة البيانات
cd ../supabase
npm install
```

### 3. **إعداد متغيرات البيئة**

أنشئ ملف `.env` في المجلد الجذر:

```env
# Supabase
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# OpenAI
OPENAI_API_KEY=your_openai_api_key

# API
VITE_API_BASE_URL=http://localhost:3005
```

### 4. **تشغيل Supabase محلياً**

```bash
# من المجلد الجذر
supabase start
```

### 5. **تشغيل التطبيقات**

```bash
# في terminal 1 - تشغيل التطبيق
cd sham-app
npm start

# في terminal 2 - تشغيل الخادم
npm run dev:server
```

### 6. **إعادة تعيين قاعدة البيانات والبذر**

عند البدء من جديد، أعد تعيين قاعدة البيانات واملأها بالبيانات التجريبية:

```bash
# من المجلد الجذر - إعادة تعيين قاعدة البيانات
supabase db reset

# بذر البيانات التجريبية
cd supabase
npm i
npm run seed:dev
```

هذا سيقوم بـ:
- إعادة تعيين قاعدة البيانات لحالة نظيفة
- إنشاء مستخدمي المصادقة بـ UUIDs ثابتة
- بذر المستخدمين والمنتجات والفئات وبيانات الموقع
- إعداد بيئة التطوير الكاملة
